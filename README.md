# Java Data Structures Implementation

This repository contains implementations of various data structures in Java. The project includes:

## Data Structures Implemented

* Linked Lists
  * Single Linked List
  * Double Linked List
  * Circular Linked List
* Stack
  * Array-based implementation
  * Linked List-based implementation
* Queue
* Dequeue

## Project Structure

* `CircularLinked/`: Implementation of circular linked list
* `Dequeue/`: Dequeue implementation with related problems
* `DoubleLinkedList/`: Double linked list implementation
* `LinkedList/`: Single linked list and its variants
* `Queue/`: Queue implementation
* `Stack/`: Stack implementations and related problems

## Getting Started

To use these implementations:

1. Clone the repository
2. Navigate to the specific data structure directory
3. Compile the Java files: `javac *.java`
4. Run the main class: `java Main`
